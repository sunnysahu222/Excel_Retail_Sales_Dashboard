# Excel_Retail_Sales_Dashboard
Sales Dashboard using Microsoft Excel

An interactive Sales Dashboard built in Microsoft Excel to analyze and visualize sales performance through dynamic charts, Pivot Tables, Pivot Charts, and Slicers. The dashboard enables users to monitor key business metrics such as total sales, monthly target vs. actual sales, top customers, top-selling products, regional performance, country-wise sales distribution, and weekly sales trends.

Features
📊 Interactive dashboard with Slicers for Month and Region
📈 Monthly Target vs. Actual Sales analysis
💰 Total Sales KPI
🏆 Top 3 Customers and Top 10 Products
🌍 Region-wise and Country-wise Sales Visualization
📅 Weekly Sales Trend Analysis
⚡ Built using Excel Pivot Tables, Pivot Charts, Maps, and Dashboard Design techniques
Tools & Skills Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Maps Chart
Data Visualization
Dashboard Design
KPI Reporting

This project demonstrates how Excel can be used to create an interactive business intelligence dashboard for analyzing sales data and supporting data-driven decision-making.
